# 🌐 React Practice – Hooks and Components

---

## 🧭 Project Overview

This project contains a collection of small React exercises and components created to practice React fundamentals, TypeScript, and custom hooks.
Each folder focuses on a specific concept such as component logic, state management, event handling, or React hooks usage.

---

## 🧱 Technologies Used

- **React*

- **TypeScript**

- **SCSS / CSS Modules**

---

## 📱 Features

- CounterForm – counter that increases/decreases by 5 and includes a live preview form with name and phone fields.

- Button – simple button component that triggers an alert on click.

- SearchForm – search input managed by a custom hook useSearchForm.

- Custom Hooks Practice – folders like Timer, EffectList, useMemo, and ToggleButton demonstrate different React hooks in use

- Reusable Components – modular and scalable component structure for easy learning and testing.
